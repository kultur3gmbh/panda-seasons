# Pre-migration calendar backup

`casa-pepe-calendar-3299-v0.6.4.json` is the MCP snapshot taken immediately before the 0.7 data consolidation on 25 October 2026.

It contains the published calendar, all 24 doors, editor layers, content, positions and settings. It contains no subscriber addresses, consent events or delivery logs. Attachment references are WordPress IDs from casa-pepe.com and are therefore intended for recovery on that same installation.

The 0.7 migration updates the existing WordPress posts in place. This snapshot is an additional recovery reference and is not included in the installable plugin ZIP.
