Interactive seasonal calendars with one responsive cover image spanning all doors. Web calendars work independently; email delivery requires the free ContactPanda plugin.

== Description ==

Create multiple parallel calendars, schedule individual doors, use separate desktop and mobile cover images, and optionally deliver each day's content by email through ContactPanda.

Use `[panda_seasons id="123"]` to display a published calendar.
