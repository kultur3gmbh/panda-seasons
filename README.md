# Panda Seasons

Panda Seasons creates interactive, date-controlled calendars for WordPress. Its visual composer places freely movable and resizable doors directly over a desktop or mobile calendar image. Clicking a door opens its content in a modal.

The web calendar works on its own. Email-calendar subscriptions and daily delivery require the free ContactPanda plugin.

## Version 0.7.0

The 0.7 line consolidates the prototype-era data fields, editor assets and template transport. Existing calendars are migrated in place to the canonical data contract; subscriber and consent records are never part of calendar exports.

- Multiple parallel calendars
- Calendar and door editors
- Visual drag-and-drop door composer
- Separate freeform desktop and mobile layouts
- Door content editing in a pop-up
- Optional unlock time in the WordPress site timezone
- Rich door content with image, video, audio and downloads
- Linked buttons, WooCommerce products and events
- Separate rich content for the corresponding calendar email
- Configurable door labels and colors before and after opening
- Administrative preview before the public opening time
- Separate desktop and mobile cover images
- Responsive full-image calendar canvas
- Scheduled door availability
- Shortcode output with `[panda_seasons id="123"]`
- ContactPanda-gated email subscriptions
- Double opt-in for unverified addresses
- Direct enrolment for already verified ContactPanda contacts
- Calendar-only, all-calendar, and global unsubscribe choices
- Auditable subscription and delivery records
- Duplicate-safe scheduled daily email delivery
- Standalone GitHub update channel with SHA-256 package verification
- Door editor panel beside the visual calendar instead of a pop-up
- Actual, all-closed and all-open state previews

- Independent advance signup with `[panda_seasons_subscribe id="123"]`
