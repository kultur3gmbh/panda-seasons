# Panda Seasons

Panda Seasons creates interactive, date-controlled calendars for WordPress. A shared desktop or mobile cover image spans every door while each door remains independently accessible and openable.

The web calendar works on its own. Email-calendar subscriptions and daily delivery require the free ContactPanda plugin.

## Version 0.1.0

- Multiple parallel calendars
- Calendar and door editors
- Separate desktop and mobile cover images
- Responsive shared-image door grid
- Scheduled door availability
- Shortcode output with `[panda_seasons id="123"]`
- ContactPanda-gated email subscriptions
- Double opt-in for unverified addresses
- Direct enrolment for already verified ContactPanda contacts
- Calendar-only, all-calendar, and global unsubscribe choices
- Auditable subscription and delivery records
- Duplicate-safe scheduled daily email delivery
- ContactPanda-compatible GitHub update channel
